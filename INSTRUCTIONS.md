# Rogov Analytics — Платформа анализа качества звонков и встреч

**Сайт:** https://rogov.automate-it.fun

---

## Что это такое

Rogov Analytics — это платформа для автоматического анализа качества разговоров менеджеров. Система записывает звонки и встречи, транскрибирует их, определяет спикеров, анализирует тональность и выставляет оценку качества по настраиваемым критериям с помощью ИИ.

### Возможности платформы

- **Запись онлайн-звонков** (Zoom, Google Meet, Teams) через Chrome-расширение — пишет звук вкладки + микрофон
- **Запись офлайн-встреч** через веб-рекордер прямо в браузере — работает с телефона и компьютера
- **Загрузка готовых аудиофайлов** (MP3, WAV, M4A, WebM) через дашборд
- **Автоматическая транскрипция** с определением спикеров
- **Анализ тональности** каждого высказывания (позитив / негатив / нейтрально)
- **Оценка качества по критериям** (0–10 баллов) с рекомендациями по улучшению
- **Дашборд** со статистикой по менеджерам, звонкам и компаниям

## 1. Запись офлайн-встреч (веб-рекордер)

Веб-рекордер позволяет записать живую встречу, совещание или разговор прямо через браузер. **Работает на телефоне и компьютере** — достаточно открыть ссылку.

### Как это работает

1. Откройте https://rogov.automate-it.fun/recorder на телефоне или компьютере
2. Укажите **имя менеджера** (обязательно) и **компанию клиента** (необязательно)
3. Нажмите **Начать запись** — браузер запросит доступ к микрофону, разрешите его
4. Во время записи отображаются:
   - Визуализатор звука (полоски частот)
   - Таймер с длительностью записи
   - Счётчик загруженных фрагментов (chunks)
5. По окончании нажмите **Остановить** — запись автоматически отправится на сервер
6. Появится ссылка на сессию в дашборде
7. Через **2–5 минут** результат анализа появится в дашборде

### Особенности

- Аудио отправляется на сервер каждые 10 секунд (чанками) — запись не потеряется при сбое
- Формат записи: WebM (Opus) — компактный и качественный
- Работает на iOS Safari, Android Chrome, десктопных браузерах
- Не требует установки приложений — просто откройте ссылку

### Сценарий использования

> Менеджер идёт на встречу с клиентом. Перед встречей открывает ссылку на телефоне, вводит своё имя, нажимает "Начать запись" и кладёт телефон на стол. После встречи нажимает "Стоп". Через несколько минут руководитель видит транскрипт, оценку и рекомендации в дашборде.

## 2. Запись онлайн-звонков (Chrome-расширение)

Chrome-расширение записывает звук из вкладки браузера (голос собеседника в Zoom/Meet/Teams) + микрофон пользователя, смешивает их и отправляет на анализ.

### Установка расширения

1. Скачайте архив: https://rogov.automate-it.fun/rogov-recorder-v1.3.zip
2. Распакуйте ZIP в любую папку на компьютере
3. Откройте Chrome → введите в адресную строку `chrome://extensions/`
4. Включите **Режим разработчика** (переключатель в правом верхнем углу)
5. Нажмите **Загрузить распакованное расширение**
6. Выберите папку с распакованными файлами
7. Расширение **Rogov Recorder** появится на панели расширений (иконка микрофона)

### Как записать онлайн-звонок

1. Откройте вкладку с Zoom / Google Meet / Teams / любым онлайн-звонком
2. Нажмите на иконку расширения **Rogov Recorder** на панели Chrome
3. Нажмите **Start Recording**
4. Chrome попросит разрешить запись вкладки — подтвердите
5. Если микрофон не был разрешён ранее — расширение покажет предупреждение и кнопку "Grant microphone access"
6. Во время записи отображаются:
   - Статус: **Recording** (красный индикатор)
   - Таймер записи
   - Количество загруженных чанков
7. Когда звонок завершён, нажмите **Stop Recording**
8. Расширение загрузит последний фрагмент и отправит запись на обработку
9. Появится ссылка на дашборд с результатами

### Что записывается

| Источник | Что захватывает | Пример |
|----------|----------------|--------|
| Звук вкладки (Tab Audio) | Голос собеседника, звуки из Zoom/Meet/Teams | Клиент говорит в Zoom |
| Микрофон (Mic) | Голос пользователя | Менеджер говорит в микрофон |
| **Итог** | **Смешанный аудиопоток обоих участников** | Полный разговор |

### Техническая схема

```
Вкладка с Zoom/Meet ──→ Tab Capture ──→ Web Audio API ──→ MediaRecorder ──→ Сервер
                                              ↑
Микрофон пользователя ──→ getUserMedia ──→────┘
```

- Оба потока смешиваются через Web Audio API (AudioContext, 48 kHz)
- Звук вкладки продолжает воспроизводиться пользователю (подключён к `audioCtx.destination`)
- Микрофон не воспроизводится обратно (нет эха)
- Запись в формате `audio/webm;codecs=opus`

## 3. Загрузка готовых файлов

Если у вас уже есть аудиозапись разговора, её можно загрузить вручную.

1. Откройте дашборд → вкладка **Загрузка** (https://rogov.automate-it.fun/#upload)
2. Перетащите файл в зону загрузки или нажмите для выбора файла
3. Поддерживаемые форматы: **MP3, WAV, M4A, WebM**
4. Укажите **имя сотрудника** и **компанию** (необязательно)
5. Нажмите **Загрузить и обработать**
6. Файл автоматически сконвертируется и отправится на анализ

## 4. Дашборд (Админка)

**URL:** https://rogov.automate-it.fun

Дашборд — это веб-приложение для просмотра и анализа всех записанных разговоров.

### Разделы дашборда

#### Звонки (`#calls`)
- Список всех записанных сессий с фильтрацией и поиском
- Карточки статистики: всего звонков, обработано, в процессе, ошибки
- Статус каждого звонка: `created` → `uploading` → `processing` → `completed`
- Клик на звонок открывает детальную страницу

#### Детали звонка (`#call/{id}`)
- **Аудиоплеер** — воспроизведение записи с перемоткой
- **Транскрипт** — полный текст разговора с разбивкой по спикерам
  - Клик на фразу перематывает аудиоплеер к этому моменту
- **Спикеры** — определённые участники разговора
  - Клик на имя спикера позволяет переименовать или объединить спикеров
- **Тональность** — цветовая разметка каждой фразы:
  - 🟢 Зелёный — позитивная
  - 🔴 Красный — негативная
  - ⚪ Серый — нейтральная
- **Оценка качества** — общий балл (0–10) и разбивка по критериям
- **Ключевые моменты** — важные точки разговора с таймкодами
- **Рекомендации** — конкретные советы по улучшению
- **Резюме** — краткое описание разговора

#### Менеджеры (`#managers`)
- Таблица всех менеджеров с их статистикой:
  - Количество звонков
  - Средняя оценка качества
  - Дата последнего звонка
- Клик на менеджера → список его сессий

#### Загрузка (`#upload`)
- Drag-and-drop загрузка аудиофайлов
- Поля: имя сотрудника, компания
- Прогресс-бар конвертации

#### Компании (`#companies`)
- Управление конфигурациями компаний
- Настройка регламента оценки и критериев
- Настройка словаря отрасли (word boost) для улучшения транскрипции
- Выбор движка ASR (Whisper / AssemblyAI)

## 5. Как работает анализ (Pipeline)

После завершения записи система автоматически выполняет 7-шаговый pipeline:

```
1. Склейка чанков      → объединение фрагментов в один аудиофайл
2. Транскрипция         → распознавание речи (AssemblyAI или Whisper)
3. Диаризация           → определение спикеров (кто говорил)
4. Объединение          → совмещение транскрипта со спикерами
5. Анализ тональности   → определение эмоций (ruBERT, русский)
6. Оценка качества      → LLM-анализ по регламенту (GPT)
7. Финализация          → сохранение результатов, обновление статуса
```

### Что оценивает система

- **Соблюдение регламента** — какие шаги протокола выполнены, какие пропущены
- **Критерии качества** — по каждому критерию оценка от 0 до 10 с комментарием
- **Итог разговора** — продажа, назначена встреча, эскалация, потеря клиента и т.д.
- **Ключевые моменты** — с таймкодами для быстрого перехода в аудиоплеере
- **Роли спикеров** — автоматическое определение кто менеджер, кто клиент

## 6. Настройка оценки под компанию

Система поддерживает индивидуальные настройки для каждой компании.

### Что можно настроить

| Параметр | Описание | Где настраивается |
|----------|----------|-------------------|
| Регламент (протокол) | Шаги, которым должен следовать менеджер | Дашборд → Компании |
| Критерии оценки | По каким параметрам оценивать (вежливость, знание продукта и т.д.) | Дашборд → Компании |
| Словарь отрасли (word boost) | Специфические термины для улучшения распознавания | Дашборд → Компании |
| Движок ASR | Whisper (локальный) или AssemblyAI (облачный) | Дашборд → Компании |
| Сценарии | Разные протоколы для разных типов звонков | Файл конфигурации |

### Что нужно предоставить руководителю

Для точной настройки оценки под вашу компанию предоставьте:

1. **Регламент разговора** — по каким шагам должен идти менеджер:
   - Приветствие
   - Выявление потребности
   - Презентация
   - Работа с возражениями
   - Назначение встречи / закрытие сделки и т.д.

2. **Критерии оценки** — что важно оценивать:
   - Вежливость и тон общения
   - Знание объектов / продуктов
   - Работа с ценой
   - Назначение следующего шага и т.д.

3. **Сценарии звонков** (если отличаются):
   - Первичный входящий звонок
   - Исходящий звонок (холодный/тёплый)
   - Запись офлайн-встречи (показ объекта)
   - Звонок после показа

4. **Примеры звонков** — хорошие и плохие, для калибровки оценки

> Текущие настройки: используется стандартный регламент для агентства недвижимости. После получения ваших критериев настроим оценку в разделе **Компании**.

## 7. Часто задаваемые вопросы

### Работает ли рекордер на телефоне?
**Да.** Веб-рекордер (https://rogov.automate-it.fun/recorder) работает в мобильных браузерах (Safari на iPhone, Chrome на Android). Просто откройте ссылку, разрешите доступ к микрофону и начните запись.

### Нужно ли устанавливать приложение?
**Нет** для записи через веб-рекордер — работает прямо в браузере. Для записи онлайн-звонков (Zoom, Meet) нужно установить Chrome-расширение (только на компьютере).

### Chrome-расширение работает на телефоне?
**Нет.** Chrome-расширения не поддерживаются на мобильных устройствах. Для записи с телефона используйте веб-рекордер.

### Что если интернет пропадёт во время записи?
Запись продолжится локально. Чанки, которые не удалось отправить, попробуют загрузиться при восстановлении связи.

### Сколько длится обработка?
Обычно **2–5 минут** для записи до 30 минут. Для длинных записей (1+ час) обработка может занять до 10 минут.

### Какие форматы поддерживаются для загрузки?
MP3, WAV, M4A, WebM.

### Можно ли исправить ошибки распознавания спикеров?
**Да.** В детальной странице звонка можно кликнуть на имя спикера и переименовать его или объединить двух спикеров, если система ошибочно определила лишнего.
