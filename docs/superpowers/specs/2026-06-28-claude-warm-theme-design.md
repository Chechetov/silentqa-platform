# «Claude-warm» тёмная тема дашборда (де-зелёный/де-GitHub-dark)

**Дата:** 2026-06-28
**Ветка/воркспейс:** `multi-tenant-core-phase1` в `/root/projects/silentqa-dev`
**Статус:** дизайн утверждён на брейншторме (пользователь делегировал вкус, выбрал референс «Claude/Anthropic тёплый, коралл», дал «го»). Объём = тёмная тёплая тема; светлый ivory-режим + переключатель — возможный фоллоу-ап, НЕ в этой итерации.

## Зачем

Дашборд сейчас — холодная GitHub-dark палитра (`#0d1117` сине-серый фон) + Material-зелёный акцент `#4CAF50`. Пользователь хочет «подстроиться под дизайн кода (Claude/Anthropic) по цветам»: тёплые поверхности + коралловый акцент. Заодно зелёный сейчас перегружен — он одновременно **бренд-акцент** (кнопки, навигация, лого) и **семантика «хорошо»** (позитивный сентимент, высокий балл); это разводим.

## Принципы

1. **Токен-first.** Палитра централизована в `:root` (`styles.css:11-32`), `var(--accent)` ×40, `var(--border)` ×43 и т.д. Базовая смена темы = правка `:root`. Остальное — вычистка захардкоженных литералов, дублирующих/обходящих токены.
2. **Развести бренд и семантику.** `--accent` (коралл) = бренд/интерактив (кнопки, активная навигация, лого, фокус). Новый `--good` (сейдж-зелёный) = только «хорошо» (позитив, высокий балл). Зелёный больше НЕ бренд.
3. **Одна холодная нота.** Тема тёплая, но `--info` остаётся сдержанно-холодным (приглушённый голубой) — для «информационных» бейджей/ссылок, ради читаемой семантики. Прежний яркий синий из заметных мест (активная строка транскрипта) убираем в коралл.
4. **Без структурных правок.** Только цвета/токены. Разметку, компоненты, отступы не трогаем (кроме мелкой полировки фокус-колец/границ за счёт токенов).
5. **Консистентность по всем поверхностям** `backend/static/`: дашборд (`styles.css` + инлайны `app.js`), платформенная админка (`admin.html` `<style>`), страница загрузки (`download/index.html` — своя палитра).

## Миграция захардкоженных литералов (аудит)

«Холодные» и «бренд-зелёные» литералы, не проходящие через токены, нужно вычистить, иначе тема «лоскутная».

### `styles.css`
- `#58a6ff` (литералы): `:451` цвет ссылки → `var(--accent)`; `:605` `border-left` активной строки транскрипта → `var(--accent)`; `:626` → `var(--accent)`. Активная строка: фон `rgba(88,166,255,.08)` (`:604`) → `rgba(217,119,87,.10)`.
- `rgba(88,166,255,.15)` (tpl-kind-extraction `:1534` и др.) → оставить `var(--info)`-совместимым: `rgba(126,167,196,.15)`.
- `#4caf50`/`#45a049` литералы → если бренд-контекст → `var(--accent)`; если «хорошо» → `var(--good)`. `rgba(76,175,80,*)` (зелёные подложки) → коралл `rgba(217,119,87,*)` для бренда / `rgba(132,168,108,*)` для «хорошо» — по контексту (score-circle high, sentiment positive = `--good`).
- Холодные bg/border/text-литералы, дублирующие токены (`#0d1117`,`#161b22`,`#1c2128`,`#21262d`,`#30363d`,`#e6edf3`,`#8b949e`,`#484f58`) → заменить на соответствующие `var(--…)`.
- `#f85149`/`rgba(248,81,73,*)` (danger) → `var(--danger)` / тёплый-красный rgba от нового danger.
- `#d29922`/`rgba(210,153,34,*)` (warning + моя подсветка поиска) → **оставить** (тёплые, уже в гамме). Подсветка поиска `rgba(210,153,34,.30/.65)` гармонична — не трогаем.
- `#ffcc00`/`#ff9800` (score/sentiment) → тёплые, оставить или свести к `--warning`.
- Прочие категориальные (`#ba68c8`,`#a371f7`,`#4285f4`,`#26c6da`,`#b0bec5`) → если это спикеры/чарты — привести к тёплому набору выше.

### `app.js` (инлайн-стили)
- `#58a6ff` ×3 → `var(--accent)` или `var(--info)` по смыслу (активные/инфо-акценты → coral/info).
- `#4caf50`/`#2e7d32`/`#238636` (зелёные: score/sentiment/status) → score high & sentiment positive → `var(--good)`; если бренд → `var(--accent)`.

- `#fff`/`#eee`/`#888` → оставить (нейтральные) или свести к токенам текста.

Проверить на холодные литералы (синие/зелёные/холодные серые) и привести к токенам/тёплым значениям. `admin.js` — без хардкод-цветов (✅).

## Маппинг семантики (чтобы смысл не потерялся)
- **Балл (score-circle):** высокий → `--good`; средний → `--warning`; низкий → `--danger`.
- **Сентимент:** позитив → `--good`; нейтрал → `--text-secondary`; негатив → `--danger`.
- **Статус-бейджи** (`badge-*`): completed/processing/failed — completed → `--good`, processing → `--info`/`--warning`, failed → `--danger`.
- **Бренд/интерактив:** primary-кнопки, активный пункт навигации, лого, фокус-кольца, активная строка транскрипта → `--accent` (коралл).

## Полировка (бонус «приятно удивить», за счёт токенов)
- Фокус-кольца интерактива → коралл (`--accent`), читаемая видимость.
- Активная строка транскрипта → тёплый коралл-tint (вместо холодного синего).
- Янтарная подсветка поиска уже ложится в тёплую гамму (бонус-консистентность).
- Лого-плашка (`styles.css:73`, `--accent` фон) → коралл.

## Вне scope
- **Светлый ivory-режим + переключатель** — отдельная итерация (структура токенов это упростит: добавить `:root[data-theme=light]`).
- Изменения вёрстки/компонентов/типографики (только цвет).
- Десктоп-приложение/расширение (отдельные кодовые базы со своим стилем).
