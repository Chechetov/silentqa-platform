# Rogov Recorder — Yandex Browser Extension

Расширение для записи звонков (Zoom, Meet и др.) в Яндекс.Браузере. Идентично Chrome-расширению — Яндекс.Браузер полностью совместим с Chrome Extension API (tabCapture, offscreen, MV3).

## Установка (Developer Mode)

1. Откройте Яндекс.Браузер
2. Перейдите по адресу `browser://extensions/`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажмите **Загрузить распакованное расширение**
5. Выберите папку `extension-yandex/`
6. Расширение появится в панели расширений

## Использование

1. Откройте вкладку с аудио/видео-звонком (Zoom Web, Google Meet, Telegram Web и др.)
2. Нажмите на иконку расширения в панели браузера
3. Разрешите доступ к микрофону (при первом использовании)
4. Нажмите **Start Recording**
5. Для остановки нажмите **Stop Recording**
6. Дождитесь окончания обработки — ссылка на результат появится в панели расширения

## Известные особенности

- Яндекс.Браузер может отставать от Chrome по версии Chromium. Если `offscreen` API недоступен, расширение может не работать — в этом случае используйте Chrome.
- `host_permissions` для `https://rogov.automate-it.fun/*` позволяет обходить CORS — убедитесь, что разрешения предоставлены.
